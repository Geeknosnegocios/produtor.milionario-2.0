Verificar Node: abra terminal e rode node --version — precisa retornar v18.x ou superior.

01
Passo 01 · Instalar Claude Code
01
Instala via npm global

Claude Code é um CLI npm. Instala 1 vez, funciona em qualquer pasta do sistema.

Windows: rode PowerShell como administrador. Mac/Linux: pode precisar de sudo dependendo da config do npm.
Sucesso: terminal exibe versão do Claude Code após install.
# instalar Claude Code globalmente npm install -g @anthropic-ai/claude-code added 47 packages in 12s ✓ claude-code@1.x.x installed # verificar instalação claude --version claude-code 1.x.x # ou com npx (sem instalar global) npx @anthropic-ai/claude-code --version
02
Passo 02 · Autenticar
02
Login via browser

Claude Code abre browser automaticamente. Autoriza na Anthropic. Token salvo localmente.

Alternativa: set ANTHROPIC_API_KEY=sk-ant-... no ambiente — Claude Code usa direto sem login interativo.
Sucesso: prompt > aparece no terminal. Claude Code está pronto.
claude login Abrindo browser para autenticação... → console.anthropic.com/oauth/authorize ✓ Autenticado como andrey@geekacademy.site ✓ Token salvo em ~/.claude/credentials # ou via variável de ambiente (CI/automação) export ANTHROPIC_API_KEY=sk-ant-api03-... claude > pronto para usar

04
Passo 04 · Abrir projeto
04
Antigravity + Claude Code

Antigravity é o IDE AI-native do Google. Abre o projeto e Claude Code roda no terminal integrado — sem Alt+Tab.

Alternativa: qualquer pasta funciona. Antigravity só melhora o fluxo — não é obrigatório para rodar as skills.
Crie uma pasta limpa para cada produto — Claude Code lê o contexto do diretório atual.
# criar pasta para seu produto mkdir meu-produto && cd meu-produto # abrir no Antigravity (se instalado) antigravity . # ou abrir terminal nessa pasta e rodar claude # Claude Code inicia lendo a pasta > Claude Code pronto > Skills disponíveis: /pesquisar-nicho > /modelar-produto > /criar-lowticket
