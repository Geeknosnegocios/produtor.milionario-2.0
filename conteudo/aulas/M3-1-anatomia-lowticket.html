Produto #1

Front-end: a isca perfeita

1 problema só
Resolve apenas o que prometeu. Não tenta ensinar tudo. Resultado claro em prazo definido.
Quick win obrigatório
O comprador precisa sentir resultado rápido. Slide 1 já entrega valor. Constrói confiança para o upsell.
Não é para lucrar
Front-end paga o tráfego (breakeven). O lucro vem do order bump e upsells. Não force o ticket alto aqui.

Regra de ouro: o front-end deve criar uma "dívida de gratidão". O comprador fica tão satisfeito que quer mais. Esse "mais" é o upsell.

Produto #2

Order Bump: R$0 de custo, 30-50% de adesão

  • Aparece como checkbox na tela de checkout — 1 clique para adicionar
  • Preço baixo: R$10-27 — não pode fazer o cliente abandonar o carrinho
  • Complementa o front-end: "como usar melhor o que você acabou de comprar"
  • Zero custo de tráfego: cliente já está na página de pagamento, comprou a atenção
  • Copy do OB: 3 frases max. Benefício direto. "Adicione também [item] por apenas R$17 e [resultado]."

Produto #4 e #5

Upsell #2 e Downsell: segmentando o público

Upsell #2 — Premium (R$197+)
Para quem quer o resultado máximo. Mentoria em grupo, comunidade exclusiva, implementação, templates avançados. Aparece para quem aceitou o Upsell #1.
Downsell — Para quem recusou
Versão reduzida do upsell por preço menor. "Tudo bem, sem problemas. Mas antes de sair, tenho uma versão menor por R$37..." Captura 15-25% dos que recusaram.

No Cakto: configure o fluxo em sequência. Quem aceita upsell #1 → vai para #2. Quem recusa #1 → vai para downsell. Quem recusa downsell → vai para página de obrigado.

Percepção de valor

Value stack: explodir o valor percebido

// Exemplo: PixIA — R$27

✅ Guia PixIA completo .............. valor: R$97
✅ Método P.I.X. (7 Jobs) .............. valor: R$67
✅ Templates de Prompt .............. valor: R$37
✅ Checklist de Entrega .............. valor: R$27
✅ Bônus: Scripts WhatsApp .............. valor: R$47

Total real: R$275 → HOJE: R$27 (90% off)

Regra: cada bônus deve ser tangível e ter nome próprio. Não invente valores absurdos — deve ser crível. R$47-97 por módulo/guia é razoável.
