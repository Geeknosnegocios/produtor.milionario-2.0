Por que o Pixel Importa

Sem rastreamento correto, o algoritmo Meta não sabe quem converter.

PIXEL ERRADO / AUSENTE
  • Algoritmo otimiza para clique, não compra
  • CPL baixo, CPA alto (cliques baratos, vendas caras)
  • Criativo bom parece ruim porque não converte no dados
  • Remarketing sem audiência qualificada
  • Lookalike fraco — baseado em dado errado
PIXEL CORRETO + CAPI
  • Algoritmo aprende perfil de quem compra
  • CPA cai com o tempo (otimização real)
  • Lookalike baseado em compradores reais
  • Remarketing qualificado (visitou PV mas não comprou)
  • Dashboard mostra CPA real por criativo

Eventos por Página do Funil

Cada página do funil dispara um evento específico. Nunca o mesmo evento em duas páginas.

Página de Vendas
→ ViewContent value: 0, currency: BRL
Checkout (Cakto)
→ InitiateCheckout value: 27, currency: BRL
Obrigado (pós-compra)
→ Purchase value: 27, currency: BRL ✅
Upsell #1
→ ViewContent content_name: upsell1
Obrigado Upsell
→ Purchase value: 67, currency: BRL

Código padrão no <head> + evento específico no <body>.

<!-- Pixel base no <head> -->

CAPI — Conversions API

Server-side tracking. Sobrevive a bloqueadores de anúncio e iOS14+.

📱
iOS 14+ problem
Apple bloqueia Pixel no browser → CAPI envia direto do servidor
🚫
Ad blockers
30% dos usuários bloqueiam JS → CAPI cobre essa perda
🔄
Redundância
Pixel browser + CAPI server = match rate 70%+ (ótimo para algoritmo)
🔗
Integração Cakto

Campanha Otimizada para Compra

Objetivo errado = tráfego errado = não vende.

✗ ERRADO — Objetivo Tráfego
Meta traz cliques baratos → usuários que NÃO compram
CPM baixo · CPA alto · algoritmo confuso

✓ CORRETO — Objetivo Conversões (Purchase)
Meta busca perfil de quem compra no mercado
CPM maior no início · CPA cai com 50+ conversões
  • Objetivo: Conversões → Pixel → evento Purchase
  • Orçamento inicial: R$50–100/dia por adset
  • Fase de aprendizado: 7 dias — não mexer em nada
  • 50 Purchase/semana sai da aprendizagem e otimiza de verdade
  • Lookalike: criar audiência de compradores → lookalike 1% após 100 compras
