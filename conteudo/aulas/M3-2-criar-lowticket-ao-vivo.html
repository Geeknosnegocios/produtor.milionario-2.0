em Tempo
Real.

15 minutos. 1 comando. Produto completo com briefing, copy black e índice de conteúdo — direto do Claude Code.

⏱ 15 min 🤖 automático 📦 produto pronto
CLI 1 comando
O que você recebe

O skill entrega 3 arquivos completos em 15 minutos

briefing.md
Visão geral completa: título com 3 ângulos A/B/C, público, dor, emoção dominante, formato de entrega, funil e preços.
copy-black.md
5 headlines × 5 ângulos, 7+ bullets, 3 hooks Meta 3s, value stack explodido, garantia, 3 CTAs, 3 captions IG.
entregavel.md
Índice completo do produto: capítulos, conteúdo de cada seção, checklist final. Pronto para o Canva ou Claude redigir.
Tudo salvo em operacoes/lowticket/produtos-modelados/[nome-produto]/
Passo 1

Passando a ideia para o Claude

// Sintaxe do comando:
/criar-lowticket [ideia]

// Exemplos válidos:
/criar-lowticket receitas para diabéticos semana 1
/criar-lowticket guia para conseguir primeiro emprego CLT
/criar-lowticket 7 jobs com ChatGPT pelo celular
/criar-lowticket planilha financeira para casais

// O skill decide automaticamente:
→ formato (PDF, planilha, checklist, template)
→ preço (R$17 a R$47 com justificativa)
→ ângulo (ego, dor, FOMO, revelação, identidade)
Output 1/3

briefing.md: estratégia completa

// briefing-ativo.md (exemplo gerado)

PRODUTO: PixIA — Primeiro Pix em Minutos
TÍTULOS A/B/C:
  A: "PixIA — Primeiro Pix em Minutos com ChatGPT"
  B: "Método P.I.X.: 7 Jobs que Pagam Hoje"
  C: "ChatGPT no Celular: Primeiro Pix em 1 Hora"

PÚBLICO: mãe solo 25-45 D/C, demitida, dor financeira aguda
DOR: conta vermelha, marido cobrando, vergonha social
PREÇO: R$27 front · OB R$17 · Upsell R$67 · Upsell #2 R$197
FORMATO: PDF 40p + templates de prompt + checklist
Output 2/3

copy-black.md: 11 blocos prontos

  • 5 Headlines — ego · dor · FOMO · revelação · identidade
  • 3 Hooks Meta 3s — brutais, param o scroll
  • 7+ Bullets — [resultado] + [como/sem o quê]
  • Value Stack — entregáveis com valores individuais
  • Garantia — seca, confiante, sem "satisfação"
  • 3 CTAs — resultado · urgência · provocação
  • 3 Captions Meta — ego · FOMO · resultado (150 palavras)
Output 3/3

Agora: rode /criar-lowticket com seu produto

  • Abra o Claude Code na pasta do projeto
  • Digite: /criar-lowticket [nome do seu produto validado]
  • Aguarde 5-10 minutos — Claude vai gerar os 3 arquivos
  • Revise o briefing.md — ajuste público ou preço se precisar
  • Abra o copy-black.md — já tem tudo para a página
  • Salve o entregavel.md — vai usar para produzir o PDF
