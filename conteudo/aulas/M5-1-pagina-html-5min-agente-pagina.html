Animações que Convertem

Quatro animações obrigatórias — cada uma com função de conversão.

Scroll Reveal
`.reveal` + IntersectionObserver — seções aparecem ao scrollar, cria sensação de progressão
Count-Up
`.count-up[data-target]` — números sobem de zero em prova social, ancora credibilidade
CTA Pulse
`@keyframes pulse` no botão principal — chama atenção sem ser irritante
CTA Sticky Mobile
Barra fixa aparece após scroll do hero — presente em toda a jornada do mobile
/* count-up automático */
<div class="count-up" data-target="2847">0</div>
<div class="count-label">alunos ativos</div>

Deploy em 3 Passos

Do HTML gerado ao link público em menos de 60 segundos.

1
Criar repo GitHub com o HTML
2
Conectar repo no Vercel
3
Git push → auto-deploy
# setup inicial (1x)
git init && git add . && git commit -m "init"
gh repo create pv-meu-produto --public --push
vercel --prod

# updates (toda vez)
git add . && git commit -m "update" && git push
# Vercel detecta push e re-deploya automaticamente (~30s)
